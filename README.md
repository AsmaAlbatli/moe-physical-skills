# منصة المهارات البنية — المرحلة الابتدائية

منصة عربية تفاعلية لمنهج المهارات البنية (المهارات الحركية الأساسية) للمرحلة الابتدائية، من إعداد **المعلمة تهاني الباتلي**.

تعمل المنصة مباشرة في المتصفح، وتناسب الجوال والجهاز اللوحي والحاسوب، ولا تحتاج إلى تثبيت أي تطبيق.

## الرابط

**https://asmaalbatli.github.io/moe-physical-skills/**

يمكن فتح الرابط من أي جوال، أو مسح رمز QR الموجود داخل المنصة من زر **«تعمل على الجوال»**.

## المحتوى

- **٦ مراحل دراسية:** من الصف الأول إلى الصف السادس الابتدائي.
- **٤ رياضات في كل مرحلة:** كرة القدم، الجري، الوثب والقفز، كرة السلة.
- **٢٤ اختبارًا مصورًا:** ثلاثة أسئلة بسيطة لكل اختبار.
- **٧٢ نجمة:** ثلاث نجوم لكل اختبار، وتُحفظ أفضل نتيجة تلقائيًا على جهاز الطالب.
- **٤ مقاطع فيديو قصيرة:** من يوتيوب، مع مصغرات محلية ونوافذ مشاهدة مدمجة.
- **رسومات تعليمية أصلية:** بصيغة SVG، خفيفة وواضحة على جميع الشاشات.
- **تغذية راجعة فورية:** إجابة صحيحة أو خاطئة مع شرح مبسّط، ونتيجة ونجوم في النهاية.
- **مؤثرات صوتية وكونفيتي:** يمكن إيقاف الصوت من زر المؤثرات في الأعلى.

## طريقة الاستخدام

1. اختر الصف من شريط المراحل.
2. اختر الرياضة التي تريد تعلّمها.
3. شاهد المقطع القصير أو ابدأ الاختبار مباشرة.
4. أجب عن الأسئلة الثلاثة، ثم شاهد نتيجتك ونجومك.
5. أعد المحاولة لتحسين نتيجتك، أو انتقل إلى مهارة أخرى.

تُحفظ النتائج في `localStorage` تحت المفتاح `thf-physical-skills-v1`، ويمكن حذفها من زر **«إعادة ضبط تقدمي»** في التذييل.

## التشغيل محليًا

الموقع ثابت بالكامل (HTML/CSS/JavaScript)، ويمكن تشغيله بأي خادم ملفات بسيط:

```bash
python -m http.server 8765
```

ثم افتح:

```text
http://127.0.0.1:8765/
```

## النشر على GitHub Pages

الموقع منشور من فرع `main` في المستودع:

```text
https://github.com/AsmaAlbatli/moe-physical-skills
```

لتفعيل النشر:

1. افتح إعدادات المستودع.
2. اختر **Pages**.
3. اختر **Deploy from a branch**.
4. حدّد الفرع `main` والمجلد `/ (root)`.
5. احفظ الإعدادات وانتظر دقيقة حتى يظهر الرابط.
